# Changelog

All notable changes to NexPlay public releases are documented here.

## [1.0.0] - 2026-09-07

### Added

- Native Android local-first audio and video playback.
- Folder-based media browsing and media search.
- Canonical playback queue with shuffle and repeat.
- Persistent playlists.
- Native Audio Player and Audio Mini Player.
- Native Video Player with portrait and landscape fullscreen playback.
- Background audio playback through Android MediaSession.
- Notification, lock-screen, headset, and Bluetooth transport controls.
- A-B Repeat.
- High-quality embedded audio artwork.
- Video Audio Only mode.
- Fullscreen Child Lock with persistent local unlock pattern.
- Share and media details actions.
- Android Open With support.
- System, Light, and Dark themes.
- Folder media sorting.
- Draggable fast scrolling for long media lists.
- Local application preference persistence.

### Fixed

- Hardened system-bar behavior for video playback across older Android devices.
- Prevented shared scrollbar thumb sizing from crashing during transient fullscreen rotation resize.

### Release Notes

- First signed public NexPlay release.
- Application ID: `com.nexplay.app`.
- Version code: `1`.
- Minimum Android version: Android 6.0 / API 23.
